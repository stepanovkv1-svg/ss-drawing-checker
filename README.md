# SS Drawing Checker

Программа для проверки рабочей документации (СС, КТСБ, ПС, СОУЭ, автоматика) по PDF и XLSX.
Результат — реестр замечаний в HTML (по исходному шаблону) и Excel.

Только для домашнего использования, копии не передаются. ТЗ — отдельный документ (редакция 2 от 03.11.2026).

## Сборка

Сборка под Windows выполняется GitHub Actions (`.github/workflows/build-windows.yml`).
Готовая папка — в артефактах запуска (Actions → запуск → Artifacts).

Ограничения, которые действуют всегда: без автоматизации браузера, cookies и пользовательских сессий;
исходные шаблоны не меняются без согласования; PyMuPDF не используется; без явного согласия — никаких платных операций.

## Разработка

```
pip install -r requirements-dev.txt
python -m pytest -q          # тесты, включая запрет сетевого кода вне app/gateway
python run.py                # запуск из исходников
```

Структура — по разделу 11 ТЗ: `app/` (ui, documents, data, …), `tests/`, `spikes/` (испытания Э0), `tools/`, `docs/`.
